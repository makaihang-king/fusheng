# 浮生 第一章 学堂

这是 Cocos Creator 3.8.8 + TypeScript 游戏工程，第一章可游玩，后四章保留未开放入口。

当前正在按用户反馈修正跑步逆相位，并重做与背景一致的障碍素材。上轮2026-09-29的交付报告和APK仅作基线，不代表本轮修改已通过。最新进度与续作入口见[步态与障碍交接](docs/继续执行_步态与障碍重做.md)。

小满全部动作使用同一套固定骨架、头脸模板与调色板。游戏采用像素帧，结局使用同源平滑人物；换装保留脸型和身体比例。环境素材采用本机 Qwen 的游戏画风参考，结局环境动态由本机 MiniMax H3 生成，再与同源人物合成。生成记录与实际验收范围见本轮报告，历史测试不作为当前版本通过证据。

## 开始玩

双击 **启动游戏.cmd**，或运行 `node scripts/serve.cjs` 后打开 `http://127.0.0.1:4318/preview/`。本机预览不需要联网，也不需要安装 npm 包。

动作和结局审阅页：`http://127.0.0.1:4318/preview/review.html`，展示15种动作及七个结局的四种服装版本。影片只读取与当前人物、生成器 SHA 一致的成片记录；本轮验收完成前会明确显示进行中。

双击 **打开编辑器.cmd** 可进入 Cocos 工程。双击 **构建网页版.cmd** 或 **构建安卓.cmd** 生成相应产物；命令见[环境与构建](docs/环境与构建.md)。

## 操作

- 自动向前跑。轻点或空格/↑跳跃，空中再次操作二段跳。
- 向下滑或↓：地面滑铲，空中急坠。三把凳子要跳起后急坠落座。
- 特定情境长按，键盘用 E；物品栏点按，键盘用 1/2/3。
- Esc 暂停。暂停页会显示最近的段首存档位置，并可手动保存；回廊可继续存档、购物、换装、看成就及首次结局快照。章节入口的“重新开始”会覆盖当前继续存档。

生命用尽退回本段，可以继续。四个正常结局点亮四盏灯后，回廊尽头的墙会裂开。

## 动作、障碍与结局

固定人物参数见[小满固定模型与动作参数](小满固定模型与动作参数.md)及 `xiaoman-model.json`。滑铲包含入铲、低姿、起身过渡，保持原来的骨长与48×48画幅。

所有障碍有地面或背景来源，动态车门、柜门、横幅按预计接触时间提前预告。车门需要二段跳，高横杆允许低姿滑过。玩家画面不显示碰撞框。实体几何、预告时间和操作规则见[障碍与碰撞规则](docs/障碍与碰撞规则.md)。

七个结局影片各12秒，游戏接两秒字卡；四种服装分别出片，共28片。首次完整播放后才结算；缺片时使用同片的24张关键帧，缺帧会停止并提供重试或无奖励返回。私人回忆终局为10秒录像、1秒黑场、2秒名言和2秒谢幕，总15秒；私人录像有独立完成证明。

## 验收与扩展

- `node scripts/build.cjs`：严格编译公共 TypeScript 代码。
- `npm test`：规则、剧情、动作、障碍、存档、媒体控制及宿主回归。
- `python scripts/validate-xiaoman-rig.py`：全量人物产物与固定骨架校验。
- `python scripts/audit-h3-generation.py`：实际模型执行记录、参考图哈希、16镜头完整解码。
- `python scripts/audit-ending-media.py`：28片音视频全解码、时长和帧数、672张降级帧及同源人物核验。
- `node scripts/ending-playback-check.cjs`：七片实际播放、暂停续播、领奖、重看及服装选择。
