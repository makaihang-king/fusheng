# 障碍实体与碰撞规则

所有障碍在世界坐标中预先存在，随场景接近。静态障碍不在玩家身边生成；门槛连着入口，横杆连着后方支架，书箱与工具落地。玩家看到的是物件的材料和来源，任何 `F3`、`geometryDebug` 参数或调试状态都不绘制碰撞边线。

动态事件包括路边车门、走廊上层柜门、松开后慢慢下垂的纪念横幅。事件由预计首次实体接触时间触发，不由屏幕某个横坐标触发。计算使用当前实际路面速度：普通跑动 `72 px/s`，持伞跑动 `74.88 px/s`。

| 项目 | 数值与规则 |
| --- | --- |
| 来源预告 | 至少提前 `3.2 s` 可见 |
| 事件开始 | 预计首次接触前 `2.6 s`，固定 `60 Hz` 更新最多有 `1/60 s` 的采样差 |
| 打开或下垂过程 | `0.55 s`，三次平滑插值 |
| 完全展开后的剩余反应时间 | 最少约 `2.03 s` |
| 车门 | 开门后门叶的实体范围 `13 × 52 px`，顶部距地 `52 px`，外沿触地；需要二段跳，不能从门下滑过 |
| 高横杆 | 实体 `28 × 12 px`，底部 `y=193`，地面 `y=216`，净空 `23 px` |
| 滑铲 | `0.8 s`；前 `0.12 s` 身体高度 `40→18 px`，之后维持低姿 |
| 起身 | `0.25 s`；前 `0.15 s` 保持低姿，后 `0.10 s` 从 `18→40 px` |
| 滑铲体宽 | 身体仍高于 `23 px` 时躯干宽 `14 px`，低姿时宽 `24 px`；伸出的鞋和手属于装饰 |
| 命中 | 每个障碍最多结算一次；离开身体后标记完成，保护时间内不会由同一个物件反复扣命 |
| 余烬 | 与主线共用真实实体几何；不再仅到中心时刻检查某个跳跃高度 |

死亡重试重新构建动态状态，不继承上一轮开着的车门。支线中途返回若不足完整预告时间，则该次行程省略相应动态事件，避免突然开门。坐在长椅上的两秒期间路面和动态事件一起停止，暂停也不推进事件。

`tests/obstacle-logic.test.cjs` 验证普通速度、持伞速度以及额外 `1.3×` 速度下的预告与完成时间，重试和晚进入、车门高度、滑铲过渡、单次伤害、碰撞框隐藏和全部实体的有限绘制坐标。`tests/game.test.cjs` 用真实跳跃、二段跳和滑铲输入验证七段主线、两条支线及余烬，并验证完整收集路线不会把碎片夹在障碍内。

车身和活动车门来自同一张 Qwen 母图，运行时使用 `props.obstacles.v2.vehicle.body` 和 `.door`。原图尺寸分别为 `188 × 124` 和 `56 × 82`，车体按两倍像素密度显示为 `94 × 62`。司机侧车门位于车身 x-14..x+5，门叶以该处前缘为铰链向镜头与路面斜开，远端由 x-14 移至 x-8 并下移 `11 px`；来源材质分成细条绘制，避免整块门板被横向拉伸到前轮。门洞、车内司机、门叶与接地投影保留连续关系，最终门叶与实际碰撞范围 x-8..x+5 一致。素材来源、裁切、SHA256 记录在 `build/qa/ending-films/qwen-plates/vehicle-runtime.json`。

`scripts/obstacle-visual-check.cjs` 通过实际浏览器为 15 种来源及 6 个语义变体保存出现前、展开后的画面；动态车门、柜门、横幅还各保存 9 帧连续画面。第一个参数为浏览器 CLI 路径，之后可附来源 ID（例如 `vehicle`）只刷新该来源，并保留其他来源报告。`scripts/obstacle-contact-sheets.py` 汇总为 6 张联系表和 3 段 GIF，位于 `build/qa/obstacle-sources`。这些是视觉安排，通关证据仍来自真实输入回归。视觉检查修正了门框悬于窄台阶、讲台误用门口、软垫误用书页、跳绳误用方梁、灯罩与灯臂断连、车辆白底遮住背景及车门开关不易分辨的问题。

游戏使用同一主题背景的底部材质铺出 y=205–270 的自然前景地面。角色脚、实体底部与地面 y=216 不变，避免毕业旧背景的街面 y=245–250 让角色和物件悬在墙上。两个宿主均使用源区域裁切，按原密度显示；裁片尚未载入时用背景地面采样色绘制砖板。`tests/scene-ground.test.cjs` 覆盖完整地面、源密度、绘制顺序、镜头抖动与素材加载失败。

换场会统一清除上一场景的跳跃、俯冲、滑铲、恢复和纸飞机滑翔，避免在琴房练习最后一刻俯冲后自动选择砸琴；连续的巷口跑动保留动量。结局不含运行时障碍或碰撞；首播完整视频有实际播放完成证明才点灯。缺片时只有当前目标关键帧真正显示，备用动画时钟才前进，24 帧全有证据后再显示 2 秒字卡；缺帧可重试或无奖励回廊。`tests/ending-controls.test.cjs` 与独立审查覆盖这些状态转换。
