# “你自己的十秒”真实录像复查

这段终局使用玩家本局的真实录像，是七部生成结局之后的私人回忆，不是第八部模型生成电影。回忆最多播放十秒，随后一秒空场、两秒结语、两秒谢幕，总体验十五秒。

## 实际验收方式

`scripts/personal-finale-playback-check.cjs` 在独立临时浏览器档案中，录制真实运动游戏画面为三段 MediaRecorder WebM，写入 IndexedDB。脚本真实刷新页面，再读取每段完整 Blob 的 SHA256，比较 ID、类型、大小、时长及内容哈希。随后实际解码三段录像，在实际切换片源前被动记录三次真实 `video.ended=true`、播放秒数、有效视频尺寸与真实成功回调，在第一段用 Escape 暂停，再用鼠标继续，等待十五秒回廊并读取最终保存状态。DOM `ended` 事件另作诊断记录：游戏轮询已结束标志后立即加载下一源，可能清除浏览器排队的旧 DOM 事件，所以不依赖其偶然的派发顺序。被动观察仍调用所有原方法，参数、时钟与真实回调均不改变。

录制使用真实键盘跳跃。为得到稳定安全的录像样本，脚本清空第一路线障碍和拾取；四灯与先前完成二年级的入场条件是明确的测试 fixture。三种 capture 类型是测试触发，不冒称自然死亡、找到隐藏结局或自然通关。未修改 `phaseTime`、`currentTime` 或加速游戏，也未注入假录像和假播放结果。

刷新后直接进入 fixture 不会带来正常结束按钮的鼠标焦点，因此脚本补一次真实画布空白点击，再发送带标准虚拟键码的真实键盘事件。报告记录真实 `activeElement`、trusted 键事件和游戏收到 Escape 的事件；这项修正属于自动化输入，未改生产游戏暂停代码。
