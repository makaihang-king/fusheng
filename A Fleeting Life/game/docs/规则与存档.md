# 《浮生》第一章：规则与存档

本轮动作、12秒结局影片和实际验证范围以[本轮动作与结局验收](本轮动作与结局验收.md)为准；本文带2026-09-25日期或旧APK哈希的设备数据只属于历史版本。

实现入口：`assets/scripts/Model.ts`。它不依赖 Cocos 或浏览器，画面层只负责跑动、碰撞、计时、交互和录像。文档中的制作建议不视为发布、付费或账号操作授权。

## 局内规则

- 四杆每局从 50 开始，限制 0–100。事件发生时按推力表改变四杆，事件记录用于叙事；正常结局只读四杆，按顺序判定：性格 ≥85→跑道之外；关系 ≥75→教室后排；性格 ≤40 且另三杆都在 [30,70)→明天的早自习；其余→小一号的课桌。
- 逃课后关系上限 65；无笔踩卷不改分、不推杆；剧情选择互斥，同一事件重复触发不重复推杆。笔、伞、橡皮、纸飞机是剧情随身物；半截粉笔不属于这四件。
- 普通碰撞先检查无敌、光、盾；真实掉命后无敌 0.8 秒。加命先补生命，满 3 命时存入最多 2 个库存，掉命后自动消耗。实际掉过命即失去该段无伤资格。
- 命用尽依序：回溯时光（每局一次，恢复段首生命）→复活羽毛（每局一次，原地 3 命）→地狱（每局一次）→本段重开（1 命）。“余烬”持续 28 秒，8 秒与 20 秒进入后两幕；每次进入按 seed 生成九个低障碍或高横杆，首个约在 4.65–4.85 秒，相邻障碍留安全间距，每幕均有两类障碍。seed 和障碍计划写入原生日志，便于复现。通过为 3 命、3 秒无敌、15 碎片、外貌 +8，并回到进入时的现场；失误回本段。

d2f9 基线 APK `d2f9b330…` 在 vivo V2055A 上由自然碰撞进入“余烬”，seed `1963767269` 的九个动态障碍均以真实跳/滑操作通过；游戏时间 26.469 秒仍在关卡内，约 28.264 秒回到跑段，截图显示三命，碎片从 278 增至 293。外貌 +8 与失败分支由规则回归覆盖，此次成功路线截图未单独核验外貌值。证据见[环境与构建](环境与构建.md)。5950 中间候选包另由自然碰撞进入 seed `1177806240` 的九障碍随机地狱，九次真实输入通过；26.523 游戏秒仍在关卡，约 28.257 秒返回跑段，三心恢复、碎片 82→97。证据为 `build/qa/android-hell-final-5950-v2055a-qa1/hell-report.json`；此结果不属于 D8FF 中间候选包。
- `enterSegment(key)` 记录段首快照；同 key 重入不重拍。回档恢复四杆、随身物、事件、水渍和剧情奖励状态；已消耗回廊道具、使用次数、地狱次数、加命库存、货币和成就不回滚。实际掉命/跳跃历史也不回滚，防止重试洗评分。
- 碎片使用场景稳定 ID，例如第三段的 `3:f7`；整局去重，实时入账。回档时场景可重建加命，但必须跳过 `run.collected` 中的碎片。全碎片奖励每段每局只给一次（+8）。
- `finishSegment(total)` 同时给通关、全收集、无伤三项独立评分，并记录无伤·无道具子档。90% 收集成就采用“该段收集点数 / 该段上限”，明确了原文“单局／该段”混用的实现口径。
- 梦／天堂实际进入才调用 `chooseReward(random)`，同类连续 3 次后强制换类；重复调用不会再计一局。奖励场景均持续 60 秒且免伤，梦境落地不会提前结束；糖纸按 ID 去重。梦的糖在段 7 开始激活，回溯到段首时保留糖的激活状态并重置三秒保护；天堂的光在下一次本应掉命时消耗。
- 进入任一结局时先调用 `enterEnding(id)`，立刻免伤且锁定结果；首次正常结局必须播完才调用 `finishEnding(id)` 并点亮对应的灯，提前点击旧按钮区域不会结算。七个结局影片均为12秒，再接2秒结尾字卡；实际媒体进度和完成证明控制结算，加载等待和暂停不推进。缺片时24张当前目标备用帧都须实际显示；重看结局不重复发奖。

## 跨局记录

`Profile` JSON 持久化版本、两种货币、五种道具库存、四盏灯、首次结局快照、16 项成就及累计进度、外观与当前装备、奖励保底、旧 `recordings` 兼容字段、终局已播放标志，以及当前跑段的段首 `checkpoint`。暂停菜单会显示最近存档位置；主段、支线入口和可重建的跑段状态从存档点继续，无法重建的中途选择、诗页、奖励或结局演出回到该段入口。重新开始章节会覆盖这份继续存档，已消耗的道具、已拾取的碎片/糖纸、生命库存和已结算奖励不会在恢复时重复发放。实际录像由适配层单独管理，按隐藏事件 > 掉命 > 普通高光排序，最多保留三段：

| 入口 | 当前候选索引 | 当前视频文件 | 旧候选兼容 |
| --- | --- | --- | --- |
| Canvas 预览 | `fleeting-life-s1-moments-v2`（localStorage） | IndexedDB `fleeting-life-video-moments/clips`，WebM 或浏览器支持的 MP4 | `fleeting-life-s1-moments` 中的 JPEG 帧只读回放 |
| Cocos Web | `fleeting-life-cocos-moments-v2`（localStorage） | 同一浏览器源下的 IndexedDB `fleeting-life-video-moments/clips` | `fleeting-life-cocos-moments` 中的 JPEG 帧只读回放 |
| Android | `fleeting-life-native-moments-v2`（Cocos 本地存储） | 应用私有目录 `files/fleeting-life-moments-v2/*.mp4`，H.264 视频 | `fleeting-life-native-moments` 指向的旧 PNG 帧只读回放 |

新录制按 480×270、目标 15 帧/秒采样，事件前约 2 秒加后约 1 秒；视频和索引分开持久化。Android 仅在编码成功后写入新索引；有效 v2 索引加载后清理未完成或不再被索引引用的 MP4，旧 PNG 有效文件仍可回放。Canvas 预览和 Cocos Web 视频已通过本轮浏览器验证。旧 `d2f9b330…` APK 在 vivo V2055A 的十分钟持续输入测试中由自然碰撞生成三段 480×270 原生 MP4，逐段与设备哈希一致，完整解码 41/42/42 帧且可定位到第 1 秒；证据为 `build/qa/android-recording-final-d2f9-v2055a-qa1/recording-final-report.json`。同一包的预置四灯原生终局播放 smoke **PASS**：视频区域变化 99.26%，`finalePlayed=true`，见 `build/qa/android-finale-smoke-final-d2f9-v2055a-qa2/seeded-playback-report.json`；四灯由测试注入，不代表四条真实通关。旧 PNG 实际共存和自然集齐四灯后的终局仍待验收。旧 `5dc070da…` 及更早候选包的结果只作历史证据。

5950 中间候选包在 vivo V2055A 的三段原生 MP4 文件验收 PASS：自然碰撞生成 480×270 视频，设备/本地逐段哈希一致，完整解码 40/41/42 帧，均可定位第 1 秒；证据为 `build/qa/android-recording-final-5950-v2055a-qa1/recording-final-report.json`。该报告不证明原生终局实播，也不替代 D8FF 中间候选包的录像验收。

读取存档时过滤未知 ID，修正负数/非数值、限制余额和库存；损坏 JSON 回到干净档。存储配额或写入失败不打断跑动，暂停卡片会显示失败并保留窗口，`lastSaveError` 提供重试入口。当前存储由宿主注入（浏览器通常为 localStorage）。

## 场景层调用约定

- `beginRun()` → `enterSegment(key)`。段 7 使用 `s7`、`7`、`segment7` 或 `graduation`。
- 每帧递减 `run.invincible`；糖的三秒结束同步清除 `run.candyActive`。跳跃增加 `run.jumps`。
- `damage()` 返回 `ignored/hit/rewind/feather/hell/restart`；普通 `hit` 不重开场景，rewind/restart 重建当前段；地狱结果调用 `hellResult(success)`。
- 奖励成就事件：`dreamNoGround/tableEdge/heavenChain12`；完成奖励事件：`dreamReward/heavenReward`。
- ③改分数必须在该段 `finishSegment()` 之前记入事件，才能正确评估“一分不差”。
- 黑板擦的实际擦除范围、磁铁吸附、伞加速、纸飞机滑飞、12 段角色变化、音画反馈与录像由场景/表现层实现。
- 测试：执行 `node scripts/build.cjs` 后运行 `npm test`。Model 覆盖八条表内设计向量及其他规则、边界、命与回滚、防刷、成就、奖励保底、商店和损坏存档；Game/Narrative/Subtitle 另覆盖实际场景、文案和字幕。


## 设置、鱼刺与外观槽补充

- `profile.settings.muted/reducedMotion` 和 `profile.progress.introSeen` 跨局保存；旧档默认 false，读取时只接受布尔值。设置变更后调用 `save()`。
- `run.lines` 与 `endingSnapshots[id].lines` 是从 `events` 派生的只读视图：`academic/family/social/items/self/risk/life/dream` 分别对应学业、家庭、社交、道具、自我、风险、生命、梦境八根鱼刺。一个事件可属于多条线；它们不参与正常结局判定，不作为冗余状态写盘。读档、段回滚和首次快照都由事件重新派生。
- 生命线中的 `lifeLost` 表示发生过掉命；`segment:<key>:noHit/hurt` 表示段完成评价，回档后的评分仍保留此前实际受伤记录。
- `equippedSlots.skin/charm/frame` 支持同时穿皮肤、佩挂件、装头像框。`equip(id)` 只替换该外观所属槽；`equipped` 始终同步皮肤槽以兼容旧渲染器。旧单槽存档按物品类别迁移，未知、错类或未拥有的槽位内容会被丢弃。
- 主动回到回廊时由场景层将 `run.active=false`；不自动结算结局。彩蛋从回廊进入，因此不颁发“无伞无笔”；同一次重复调用 `finishEnding` 不重复结算。
