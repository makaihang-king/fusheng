# 浮生 第一章 学堂

本目录是 Cocos Creator 3.8.8 + TypeScript 工程。第一章可完整游玩；画面与短提示音使用可替换的程序占位，后四章保留未开放入口。本轮不新增位图、背景音乐或配音。

## 开始玩

双击 **启动游戏.cmd**，或运行 `node scripts/serve.cjs` 后打开 `http://127.0.0.1:4318/preview/`。本机预览不需要联网，也不需要安装 npm 包。需使用本机已安装的 Node.js。

双击 **打开编辑器.cmd** 可进入 Cocos 工程。构建命令及实际产物见 [环境与构建](docs/环境与构建.md)。

## 操作

- 自动向前跑。轻点或空格/↑跳跃，空中再次操作二段跳。
- 向下滑或↓：地面滑铲，空中急坠。三把凳子要跳起后急坠落座。
- 特定情境长按，键盘用 E；物品栏点按，键盘用 1/2/3。
- Esc 暂停。回廊可购物、换装、看成就及首次结局快照。

生命用尽只退回本段，永远可以继续。四个正常结局点亮四盏灯后，回廊尽头的墙会裂开。
