# 本轮动作与结局验收

日期：2026-09-29。人物、16镜动态环境与28部影片已完成，桌面宿主最后一轮实播及最终 Web/APK 包资源核验通过。历史 APK 的设备结果不作为本轮通过证据。

## 小满身份与动作

`scripts/xiaoman_rig.py` 是游戏和结局的唯一人物源。游戏帧、平滑结局演员、服装、表情、水渍和程序兜底均采用同一头脸模板、固定骨长及调色板，人物没有交给模型逐姿态重画。

参数 ID 为 `xiaoman / fixed-rig-v3`，参数 SHA256 为 `012cf2ba5718ac099386ef8d39fe15830195b8993e0ebd6567ec7e8db40d4966`。完整参数及14种动作帧率见[人物参数文档](../小满固定模型与动作参数.md)，逐帧产物哈希见 `xiaoman-model.json`。

修正包括滑铲入铲和起身衔接、保持48×48画幅、坐骨贴座、伞柄随手、受伤低姿、换场清理急坠与滑翔，以及加载失败后的有限频率重试。失败请求按1、2、4、8、16、30秒退避，成功恢复后解除退避；旧回调不能覆盖新请求。

## 本机模型与真实生成

环境图由本机 Qwen Image 2.1 生成，参考原游戏画风和固定分镜布局。16张结局场景图与一张车辆母图的实际工作流、seed、执行 history、SHA256 和参考快照位于 `build/qa/ending-films/qwen-plates`，审计文件为 `executed-generation-audit.json`。

动态环境使用本机 `minimax_h3_fl2va_pruned_fp8_scaled.safetensors`，每镜头512×288、56帧、24fps、20步，首尾约束于同一张已审阅的 Qwen 图。环境运动按剧情镜头时槽慢放并插值；人物以独立30fps连续动作合成。最终影片每片12秒、360帧、1280×720、H.264 Main/yuv420p＋AAC，没有复制末帧来凑时长。实际 H3 工作流与完整解码证据保存在 `build/qa/ending-films/h3-backgrounds`。

七个故事分别对默认服装、系腰外套、雨衣、无名练习本出片，共28片；播放选择本局装备的服装。每片另有24张同片960×540关键帧，作为解码失败时的备用动画。每片 manifest 记录人物源、生成脚本、视频、背景动态源及备用帧的SHA256。

## 结算、备用动画与保存

首播按真实媒体进度播放12秒，再显示2秒字卡，总14秒。加载、暂停、停滞和失败不会冒充完整播放。备用动画只有当前目标帧确实显示才推进，24帧均有成功证据后才能结算；缺帧提供重试或无奖励返回。

重看不重复点灯、领奖或覆盖首次快照。四个正常结局点灯，两条成就支线不点灯，二年级只要求四灯。二年级影片之后的私人回忆为10秒录像、1秒黑场、2秒名言、2秒谢幕，总15秒；录像成功与生成电影分别验证，超时和迟到回调不误置 `finalePlayed`。
