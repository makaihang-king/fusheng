# 第一章流程测试

本轮动作、12秒结局影片和实际验证范围以[本轮动作与结局验收](本轮动作与结局验收.md)为准；本文带2026-09-25日期或旧APK哈希的设备数据只属于历史版本。

运行：先 `node scripts/build.cjs`，再 `npm test`（等价于运行 `tests/*.test.cjs`）。测试读取统一的 `build/` TypeScript 产物；以无 DOM 绘图桩检查真实 Renderer 的按钮、文字与有限数值坐标。

主验收逐帧调用 `update(1/60)`，只用跳跃、二段跳、滑铲和情境输入躲障碍，不修改角色位置、速度或无敌时间。四条完整主线经过七段、六抉择、奖励关及四个正常结局，再从回廊墙后走到彩蛋和终局，检查存档恢复。

覆盖范围：两支线的返回/成就结局；七个微事件及三种剧情拾取物；三种试卷结果；长按、死区、跨场输入与物品栏吞输入；梦/天堂零输入安全；梦幕二真实桌沿落地、滑下和离桌冲刺；天堂十二连锁；段首回档与地狱成功/失败；后四章禁用入口；七结局、所有面板及暂停层绘制；成就面板正文点击不穿透到下层出发门。

玩法回归：重看结局后开新局不沿用旧角色快照；伞的 1.04 倍推进；纸飞机两秒滑翔；剧情橡皮仅清一个障碍且不消耗商店黑板擦。①③⑤剧情物件要求真实接触；梦境落地仍持续满 60 秒，回溯保留段 7 梦糖；七个结局影片均12秒、结尾字卡2秒；实际播放和全部目标备用帧完成前不结算。地狱现为 28 秒三幕、每次进入按 seed 生成九个障碍，8 秒和 20 秒切幕；测试核对种子复现、间距、绘图与碰撞，并通过真实跳/滑输入跑通、恢复原现场与既定奖励。

个别边界用例直接进入目标场景；地狱用例只把生命设为一颗以缩短准备过程，仍由真实碰撞触发。主线验收不使用此设置。绘制检查用例设置场景时间，仅用于检查各个画面状态。

已有 17 项输入与接触回归：菜单必须在原按钮松开才确认，拖出或取消不触发；触摸取消不补跳、琴盖长按或购买；后台只暂停不自启；返回键依次关面板、暂停、回廊；0.12 秒预按跳跃/桌沿下滑和 0.10 秒平台宽容；巷子窗台与操场侧门的真实几何接触；死区涟漪与段末图标状态。

本轮新增叙事、字幕与物理回归：九场均有目标、动作回应和至少三个途中故事点；条件回响只依赖真实事件，三组碎片记忆按价值门槛触发，结局只引用真实记录；标题、剧情、教程分别排队并在暂停时冻结；九条路线的普通碎片可无伤全收集，旧 14.00 秒和 23.89 秒拾取陷阱已移出碰撞/落地带。障碍实心区与姿态碰撞框一致，三把凳子要脚部下降接触；受击、护盾、羽毛和减弱动态下的保护提示不使用方框无敌帧或整屏闪白。
