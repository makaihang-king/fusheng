# 第一章程序说明

本轮动作、12秒结局影片和实际验证范围以[本轮动作与结局验收](本轮动作与结局验收.md)为准；本文带2026-09-25日期或旧APK哈希的设备数据只属于历史版本。

实现依据为《浮生 游戏设计总案 S1》；本次用户要求覆盖完整第一章，保留美术和后四章入口。原文的制作建议、付费方案、上线排期没有作为额外操作授权。没有上架、支付集成或素材采购。

## 容易改错的地方

正常结局只读推杆，按叛逆≥85、封闭≥75、顺从≤40且其余在[30,70)、兜底顺序判定。`Model` 中的事件按既定表推动推杆；`Narrative` 只读取已发生事件生成局内文案和回响，不另改推杆或结局。支线结局不点灯；彩蛋仅要求四盏灯，不依赖两个隐藏动作。

生命未耗尽时只踉跄继续。耗尽按回溯、羽毛、地狱顺序处理；地狱每局一次，之后保底一命重开本段。现行“余烬”是 28 秒三幕路线：每次进入按 seed 生成九个有安全间隔的障碍，8 秒和 20 秒出现分幕提示，seed 与障碍计划写入原生日志。成功后恢复原现场时间与待触发互动；失败回本段。d2f9 基线 `d2f9b330…` APK 在真机由自然碰撞进入“余烬”，seed `1963767269` 的九个障碍以真实跳/滑通过；游戏时间 26.469 秒仍在其中，约 28.264 秒回到跑段，三命及 15 碎片奖励可见。剧情回段首时，货币、道具消耗、成就、真实掉命记录不退。碎片按对象 ID 防重捡，加命重新生成。

仅跨局进度保存。关闭游戏或主动回廊会结束本局，货币和已取得成就保留。结局重看调用首次快照，不再次发奖。保存失败不使游戏崩溃；浏览器清理站点数据会清除该入口存档。

## 本轮输入与画面约定

`Game.pointerCancel()` 只取消当前触摸/长按和未执行的输入缓冲；`appHide()` 清空所有按键并自动暂停，`appShow()` 不自动继续。浏览器失焦、页面隐藏以及 Cocos 后台事件均接入这组入口。`back()` 依次关闭当前面板、暂停、返回回廊。普通菜单按钮在同一按钮内松开才确认，局内道具在按下时即时使用。跳跃预按保留 0.12 秒，离开可站立平台保留 0.10 秒起跳宽容；巷子窗台与操场侧门读取 `interactionTarget()` 的几何并要求角色真正接触。

原生 JSB 环境可能提供 `location` 却没有 `URLSearchParams`；开发用几何调试开关先检查该构造函数是否存在，避免启动阶段异常。对应初始化回归已加入 Game 测试。

UI 固定为顶栏、剧情字幕、教程提示和段末图标四个区域；标题、剧情、教程各有独立字幕队列。字幕每卡最多两行、每行最多 25 字，长文分页，紧急回应按优先级交叉淡入；暂停时计时冻结，换场时清空。全局间距、色板与按钮状态集中在 Renderer。减弱动态收敛背景呼吸、视差、粒子、闪光、镜头震动与回廊漂浮，角色和障碍运动保留。480×270 是所有输入与美术的逻辑核心；浏览器低于 2 倍时按可用安全高度连续放大，Cocos 超宽屏用随场景变化的边框容纳核心画面。

本轮为七段与两支线补入可见目标、至少三个途中叙事点、即时动作回应和只根据真实事件出现的后续回响；六次抉择会按笔与四灯状态调整提示。碎片在每段价值达到 1/3、2/3、满罐时给角落短记忆，结局卡从本局记录选最多两条回声。程序场景中部分物件也随此前事件出现。跑段字幕保留在 HUD 上方，结束卡文字在卡片内排版。

物理接触共用 `Geometry.ts` 的角色姿态、障碍实心部分和凳面坐标。普通碎片避开障碍碰撞与跳跃落地反应区；①③⑤的剧情物件须由角色实际接触触发，三把凳子只有脚部真实下降接触才落座。巷子窗台、操场侧门与梦境桌沿仍要求几何接触。梦境落地不提前结算，完整持续 60 秒；段 7 激活的梦糖在回溯后仍生效。七个结局各为12秒影片加2秒结尾字卡，首次完整播放后才结算；首播缺片时的24张同片备用帧也须完整显示。受击反馈改用姿态、心形和短保护提示，不再用方框无敌帧或整屏闪白；减弱动态时仍能读到保护状态。

大厅绘制缓存与场景外图形裁剪减少重复绘制；教程文字有衬底，商店与换装有结果反馈，Canvas 灰度文字调整了抗锯齿显示。

## 回忆录像

事件前约 2 秒、事件后约 1 秒的 480×270 真实画面按目标 15 帧/秒采样；按隐藏事件、掉命、普通高光的优先级保留最多三段，仅首次终局自动播放。Canvas 预览和 Cocos Web 使用 `MediaRecorder`，优先 WebM，浏览器支持时也可选 MP4；视频 Blob 存入 IndexedDB。Android 使用 `RenderTexture/readPixels`、JSB/JNI 帧桥接与 `MediaCodec`/`MediaMuxer` 生成应用私有目录的 H.264 MP4，Cocos `VideoPlayer` 回放。Android 视频视图居中为 300×168.75，给终局标题与底部文字留空间；应用后台期间暂停编码超时计时。录制流只含画面，无音轨。旧 Web JPEG 和原生 PNG 候选仍可读取回放；新事件不再生成 JPEG/PNG 序列。旧 `d2f9b330…` APK 在 vivo V2055A 上由自然碰撞生成三段 480×270 MP4，逐段与设备哈希相同，完整解码 41/42/42 帧并成功定位到第 1 秒；见 `build/qa/android-recording-final-d2f9-v2055a-qa1/recording-final-report.json`。同一包的预置四灯原生终局 `VideoPlayer` 播放 smoke **PASS**：画面视频区域像素变化 99.26%，`finalePlayed=true`；四灯为测试注入，不代表四条真实路线，见 `build/qa/android-finale-smoke-final-d2f9-v2055a-qa2/seeded-playback-report.json`。旧 PNG 与新 MP4 在 Android 上实际共存、自然集齐四灯后的终局仍待验收。5950 版本的浏览器混合录像定向验收 Canvas、Cocos Web 各 6/6，确认纯旧帧不误置 `finalePlayed`，混合回放按事件时间播完才置位；5950 真机旧 PNG 回放已复现暂停菜单被遮罩挡住；预置四灯原生终局两次冷启动结果不一致（首次 `finalePlayed=false`，第二次画面播出并置 true），不能作稳定通过结论；D8FF 中间候选包已加入原生暂停遮罩修复、首播失败重试与诊断；其最终 Web 输出的混合回放 Canvas/Cocos Web 各 6/6，`MediaRecorder` 缺失时已存 WebM 回放各 1/1，见 `build/qa/finale-browser-finalrebuild-20260925.md`。D8FF 纯旧 PNG 暂停/续播单独 case PASS；预置四灯 MP4 首播虽见连续视频画面，字幕后 `finalePlayed=false`，原生终局完成置位未通过。

最新源码与 Web 输出（`build/qa/finale-browser-finalnativecomplete-20260925.md` 所列指纹）另通过 Canvas/Cocos Web 混合终局各 **6/6**、禁用 `MediaRecorder` 后已存 WebM 回放各 **1/1**；这是浏览器验收，不能证明原生终局。769D 修复尝试包 SHA256 为 `769d15f9f8d8e5193b7ca2713eae09f8a4f631d6967971dbd0c560d05d4da2d6`，预置四灯、三段 MP4 的两次冷启动后 `finalePlayed` 均为 false，原生完成置位仍未通过；该包未复制到 `dist`。EC7C 仅作诊断，不作发布候选。

## 美术与章节入口

在 Content.ts 的 ART_MANIFEST 填资源相对路径；空值保留程序画面。Renderer通过Painter.image加载背景和人物分层，碰撞框与图片独立。背景核心为480×270；小满固定48×48逻辑画幅，所有动作由同一头脸模板和骨架生成。字段和路径约定见内容说明，音频适配入口在Bootstrap/host。

CHAPTERS保留芒种、白露、霜降、冬至。当前都禁用，未填充虚构剧情。后续应为每章增加独立内容表和流程入口，不复用第一章的进度命名空间。
