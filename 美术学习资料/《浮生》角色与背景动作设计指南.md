## 〇、五条总工作原则（全部来自学习资料，贯穿下文）

1. **剪影优先**：任何角色形态、任何动作关键帧，先以纯黑剪影审读。读不出的情绪与身份，就回炉。40px 小人的全部辨识度在轮廓，不在细节。（saint11 剪影教程）
2. **关键帧优先**：所有动画先交「分色假人 + 关键帧」版本（腿/臂/头/整体分层分色），审读通过后再铺中间帧和正式图层。能量>流畅，删帧不减能量、必须同步提速。（Slynyrd 动画入门/行走循环）
3. **大块优先**：背景先立色带与大明暗关系，再进层次与簇化。宁可细节不足，不可大关系不对。平涂压平衡：大色域平涂为主、渐变点缀，天然契合像素限制与「色温叙事」。（Speed 平衡章 + Slynyrd 风景教程）
4. **色偏移贯穿一切**：每个色区的色板不是「换主色」，而是整套 HSB 规则（色相随明度偏移、饱和度峰值居中、远层向天色收敛）。角色、背景、UI 同用一套规则才有全局统一。（Slynyrd 色板教程）
5. **循环即放大镜**：跑循环、视差层、idle 会被无限次重播，一个孤立像素都藏不住。簇要干净，循环帧数要整除服务对象（视差总帧、节拍）。（Slynyrd 视差/动画教程）

## 一、角色设计（小满）应用规范

### 1.1 底版结构规格（补强 A-H1 表 3）

| 项 | 规格建议 | 依据 |
| ---- | ---- | ---- |
| 头身比 | 3.5～4 头身；头高约 10～11px | Slynyrd：头大→表情层可读；6 头身是写实下限，儿童角色取更小比例成立 |
| 面部基准（侧面） | 眼位在头高中点；眉/眼/嘴三个 1px 级位置变量 | 解剖教程五官比例，像素下抽象为 3 个 1px 变量 |
| 姿态基准线 | 默认态脊柱前倾约 5°（跑者）；档位差异=重心线±2～3° | 姿态线方法：先定脊柱线再挂肢体 |
| 剪影测试点 | 袖口/红领巾/书包带/帽檐/鞋带/发梢 6 个轮廓特征 | saint11 剪影教程：轮廓特征承载叙事 |
| 制作三步 | ①姿态线 ②分色假人（头/躯干/臂/腿分色）③正式四层 | 解剖教程三步法 + 行走循环 Dummy 法 |

### 1.2 四层三档的「层方法论」（补强 A-H1 表 5）

- **表情层 = 1px 工程**。眉、眼、嘴各是 1px 位置/明暗变量：
  - 顺从档：眉点下移 1px + 眼缝减为 1px 高（低垂）；
  - 叛逆档：眉点后挑 1px + 眼缝前缘亮 1px（挑起）；
  - 封闭档：额发/帽檐下压 1px 遮眼位 + 目光落地（瞳孔点下移）；
  - 开朗档：嘴角点前移 1px + 颊部 1px 亮斑。
  - 侧面 10px 头部最多容纳 3～4 个表情变量同时生效，一次档位变化只动 1～2 个——「渐变不是换人」的像素保障。
- **姿态层 = 重心线工程**。八档差异先体现在脊柱倾角与步幅像素数（见 3.2 跑循环差异帧表），摆臂幅度、头部稳定度次之。
- **服饰层挂轮廓特征点**：所有服饰变化（卷袖、塞红领巾、耳机、书包带松紧、泥点）必须改变剪影边缘至少 1px，否则视为无效变化——「玩家看不见数字」铁律的像素执行标准。
- **色彩层交给管线**，但基准色板的 hue-shift 规则由你拍板（见 2.1）。

### 1.3 八档位跑姿差异帧【新建议：具体做法】

基础跑循环做 8 帧（见 3.1）。八档位不重画整段循环，按 A-H1 的思路「差异帧混入」，规格化如下：

| 档位 | 混入帧数 | 差异内容（只动姿态/服饰层） |
| ---- | ---- | ---- |
| 顺从 | 每 8 帧循环混 2 帧 | 步幅 −2px、躯干直立 +2°、落脚尘减半 |
| 叛逆 | 混 2 帧 | 步幅 +2px、躯干前倾 +3°、脚跟擦地帧（落地尘后拖 1px） |
| 开朗 | 混 1 帧 | 摆臂上举挥手帧（复用变化动画④的关键帧） |
| 封闭 | 混 2 帧 | 含胸（躯干角 −2°）、双臂收拢插兜帧 |
| 坚持 | 混 2 帧 | 步频加密（8 帧加速至 ~110ms/帧播放）、头部锁定 |
| 放弃 | 混 2 帧 | 步频乱（随机删 1 帧节奏）、拖步帧（脚尖不离地） |
| 整齐 | 0 帧（姿态基准即整齐） | 落脚正、无尘 |
| 凌乱 | 混 1 帧 | 踉跄帧（重心瞬间外偏 2px，stagger 插入） |

依据：行走循环教程「步态=性格」；动画入门「差异帧混入」经济学。

### 1.4 皮肤与随身物的动画要点

- 校服外套系腰（皮肤②）：外套摆=「次要动作」层，跑循环中滞后躯干 1 帧摆动（follow-through），风效教程的等距流点法（摆宽 2px、每帧 1px、6 帧循环）。
- 雨衣（皮肤③）：配溅水粒子帧（2×2px 水点，抛物线 3 帧消失）。
- 随身物携带位拍板建议【新建议】：笔别胸前口袋（1px 露头，剪影可辨）；伞手持或背挂（背挂时伞尖超出轮廓 2px，正是剪影特征）；橡皮放裤兜（袋口 1px 鼓起）；纸飞机头顶盘旋（4 帧椭圆轨道，与跑循环 8 帧整除关系=每 2 帧移动一个轨道点）。

## 二、背景与场景设计应用规范

> 管线分工不变：Blender 低模渲 3～5 层视差图→降采样像素化，美术生验收。本章给出**验收与加工的美术标准**。

### 2.1 七套色板的 HSB 规则（任务一的落地方法）【新建议】

每区一套 16～24 色，共用同一构建法（Slynyrd 色板教程）：

1. 每条色阶 5～7 档：明度两端不到极值（最亮保留给高光、最暗保留给投影），**饱和度峰值居中**，高明度档饱和度必降；
2. 每级色相偏移 10°～20°，**方向由色区光色决定**：
   - 晨光白：亮部偏暖黄、暗部偏蓝紫（晨光冷暖对撞最典型）；
   - 正午暖黄：全阶偏黄，暗部偏褐不偏紫（干燥硬光）；
   - 黄昏橙红：亮偏橙红、暗偏紫红，饱和度整体上限最高的一区；
   - 梦境紫：亮偏粉、暗偏蓝，明度整体压低、对比放软（软投影=空气感）；
   - 深夜深蓝：亮部偏青（月光）、暗部近乎无彩，只留 1 档饱和色给灯/窗（点光源原理：夜里唯一饱和=光源本身）；
   - 天堂白金：极窄明度带 + 高明度低饱和，靠 1 档金色高光立层次（过曝=削对比）；
   - 地狱红黑：暗部无彩、亮部仅红阶，删掉全部冷色。
3. 七区共用**同一张色阶骨架**（每区同档数、同明度走向），只换偏移方向与饱和上限——这是「色区重映射」管线能批量生成的前提，也是全作统一感的来源。

### 2.2 场景分层与大气透视（每个场景节点的通用流程）

1. **色带起手**：天/地先切成 3～5 条水平色带，确定地平线；深度感首先由色带关系建立。
2. **大气透视三律**（白天区）：近层最饱和+对比最强；远层降饱和、提亮、色相向天色收敛；最远层直接复用天空色。**色偏移方向由光决定**：晨光/黄昏侧光区，受光远层向光色偏（金/橙），不受光远层向天色偏。
3. **簇化尺度递减**：最近层的草/砖/石用可辨认的 2～4px 簇；次层 1～2px 簇；再远不画单体。降采样背景同样按此验收——远景若残留高频细节，回炉。
4. **投影指示空气**：晨光白、梦境紫=软淡投影（边缘 1 档过渡）；正午、黄昏=硬边深投影（无过渡）。地狱红黑区投影近乎吞没形体。
5. **色数纪律**：单场景成品 ≤32 色（含角色占位色）；跨层复用颜色优先于新增。

### 2.3 视差层规格（管线协作标准）【新建议】

- 画布 480×270。各层每帧位移必须**整除 480**，推荐配速：

| 层 | 内容 | 每帧位移 | 依据 |
| ---- | ---- | ---- | ---- |
| L1 天空 | 渐变+云（云自身 2 层，最远云烘进天空不单独动） | 0（或 1px/2 帧，慎用） | 慢于 1px/帧易抖 |
| L2 远山/远景 | 剪影级山体、天际线建筑 | 1px | 最远动层基准 |
| L3 中景 | 树线、街区屋顶 | 2px | 递增 |
| L4 近景地面 | 跑道、课桌列、地面物件 | 4px | 与角色滚屏速度一致 |
| L5 前景 | 偶发前景遮挡（柱、树干，半透明慎用） | 8px | 强化纵深，节制的段落才用 |

- 每层左右无缝循环；**均衡无地标**的层耐重复；确需地标（钟楼、水塔）时放在中景并接受循环感，或做成超长层（2×480 循环）。
- 层内活动元素（旗、鸟、树冠波）循环帧数整除该层总循环帧数。
- 与跑速联动：角色固定速度变化段（叙事走廊减速、冲刺加速）只调 L2-L4 配速倍率，L1 天空永不变速——天空是「时间」的隐喻，不动如钟。

### 2.4 构图规范（横屏·垂直强调）

- **「巨大的天与地，人在中间」**的执行法：地平线压低（上 2/3 给天）或抬高（下 2/3 给地）二选一，**不取中间**；叙事走廊统一压低地平线（天占主导=时间感、孤独感）。
- **主线条**：每场景先答「这个场景的 leading line 是什么」——操场跑道=水平重复线；巷子=两侧向灭点汇聚线；教学楼=垂直窗列；回廊=单点透视中心辐射（Crane 辐射原理，尽头门/墙即辐射心）。
- **平涂压平衡**（Speed）：背景以 2～3 块大平色域立骨架；渐变只给天空与光带。凡「越看越躁」的背景，先删渐变和碎簇。
- **比例语言**：回廊、结局演出用整饬比例（对称、等分=宁静庄重）；跑段用参差比例（活泼）。《小一号的课桌》特写用中心对称+单一光源。
- 垂直母题物（钟、旗杆、树、门）承担「天与地之间的连接物」，构图上允许其切断地平线——这是垂直构图的视觉锚。

### 2.5 象征物与「环境会呼吸」（零文字叙事的动画规格）

- 象征物反应统一规格【新建议】：2～4 帧 sway，位移 1px，0.2s/帧（风效教程标准）：
  - 空椅子：椅面 1px 沉浮（似有重量记忆）；
  - 断线风筝：3 帧摆动+尾带 2px 波（等距流点法）；
  - 鸟笼：门缝开合 1px、内部微光 2 帧明暗；
  - 上课铃：只在对应场景入口自鸣 2 帧晃动。
- 环境风：跑段中景树冠用「分层错相位波动」（每层循环 4 帧、层间差 1 帧），草/尘用 2×2px 粒子偶发飘过。玩家跑过触发=相位重置一次即可。
- 呼应「玩家做过的事越多，回廊越像你」：回廊墙面痕迹（粉笔字、贴纸）作为**可生长图层**单独切层，供管线按成就/结局点灯叠加。

### 2.6 水渍层与其他参数层

- 裤脚湿度 4 档贴图（0/30/60/100）之外【新建议】：70+ 档给全身 1 档冷色偏移基准图（色温下降的具体值=暗部色相向蓝偏 15°），供管线混控，保证「湿度同时驱动色温与高光」的视觉一致。
- 高光层：湿=高光档 +1（ specular 提亮），干=基准。验收时用「高光只在湿侧出现」检查。

## 三、动作设计应用规范

### 3.0 全局帧率与时长标准【新建议】

| 动画类 | 帧数 | 每帧时长 | 循环 |
| ---- | ---- | ---- | ---- |
| 跑循环（基础） | 8 帧 | 80ms | 无缝循环 |
| 跑循环（减配机型/地狱段） | 6 帧 | ~105ms | 删 recoil 帧 |
| idle/呼吸 | 2～4 帧 | 200ms | 循环 |
| 跳（单段） | 4～5 帧 | 起跳 60ms/空中 100ms/落地 60ms | 单次 |
| 二段跳 | 4 帧 + 转体 2 帧 | 同上 | 单次 |
| 急坠 | 2～3 帧 | 50ms（快=重量） | 单次 |
| 滑铲 | 4 帧 | 入 60ms/持 100ms×n/出 80ms | 按住持续 |
| 12 段变化动画 | 每段 3～4 帧（三段式） | 总长 0.8～1.2s | 单次，不打断跑 |

依据：动画入门 80ms/160ms 基准；行走循环 8 帧经济与流畅平衡点。

### 3.1 跑循环结构（任务二的底子）

8 帧 = 左右腿各 4 相位：**接触→下沉→过渡→摆动**。要点：

- 接触帧全身最低、摆动腿前伸；过渡帧双腿交叉、全身最高；**头部轨迹成三角波**，不做均匀正弦；
- 手臂与异侧腿同摆（共享动量）；拳头前摆至肩高（儿童奔跑的「挥拳感」，3 帧跑循环法的能量要点）；
- 垂直弹跳量 2～3px（含在 48×48 帧盒余量内）；
- 先交分色假人 8 帧审读，通过后换四层正式图。

### 3.2 七个基础动作逐项规格

| 动作 | 关键帧结构 | 补强要点（来自学习资料） |
| ---- | ---- | ---- |
| 跑 | 见 3.1 | 档位差异帧混入（1.3）；BPM 与 BGM 对齐可选 |
| 跳 | 蓄力压扁→拉伸上升→顶点收拢→下落拉伸→落地压扁+尘 | 挤压拉伸**体积守恒**：压扁加宽 1px、拉长变细 1px；尘土「命中/打空」两版（打空=尘小而散） |
| 二段跳 | 空中再压 1 帧→转体 2 帧（背对/正对交替）→恢复 | 与一段跳的辨识度=**轮廓变化**（转体）；可加 1 帧 smear |
| 急坠 | 上举拉伸→下坠拉长→落地重压+尘环 | 时长最短=重量感；落地尘用环形扩散 3 帧（区别于跳跃的点尘） |
| 踩踏 | 触物帧 1 帧高亮 | 物件高亮帧由管线做，你出「踩踏接触姿态」（单腿下沉+重心前压）1 帧 |
| 滑铲 | 俯身入→低姿持滑（尘流）→起身 | 段 5 大人腿阵标志动作：持滑帧躯干贴水平线（姿态层极限前倾）；尘流=连续 1px 粒子带 |
| 反向滑动 | 停（1 帧）→转身（2 帧）→倒走离画 | 全作唯一「停」：停顿时全身重量下沉 2px（重量=不舍）；转身帧是彩蛋级关键帧，值得精修 |

### 3.3 十二段变化动画通则 + 示例分解

通则：三段式=预备（anticipation）→ 执行 → 跟随（follow-through）；上半身为主、腿部维持跑循环（次级动作不覆盖主动作）；总长 0.8～1.2s；每段只动所属层。

示例规格（其余十段同法拆解，逐段填入 A-H1 表 12 的「三段式」列即可开工）：

- **③ 戴上耳机**（表情层）：预备=抬手悬停 1 帧（犹豫）；执行=耳机挂颈→贴耳 2 帧（轮廓特征点变化：耳位 1px 突起）；跟随=低头 1 帧 + 红领巾摆 1 帧滞后。触发即「关系封闭档」首次生效——这一段的跟随帧要与封闭档 idle 衔接（目光落地）。
- **⑦ 扯松红领巾**（服饰层）：预备=抓（手部 1 帧特写化夸张）；执行=抽-塞 2 帧（剪影从「领口系紧」变「胸前鼓 1px」）；跟随=甩手 1 帧 + 步幅立即 +2px（姿态层同步切叛逆跑姿差异帧）——**变化动画的最后 1 帧必须正好落在对应档位的差异帧上**，这样「动画结束=新常态开始」，渐变感由衔接保证。
- **⑨ 书包带滑落**（姿态层）：预备=肩一沉；执行=带子滑 2 帧（沿手臂流点 1px/帧）；跟随=捞空 1 帧、算了 1 帧（手部停滞后自然落回跑姿）。「捞空」帧是全段情绪帧，值得单独精修。

### 3.4 特殊形态动作规格

- **回廊·苍白无脸人**：idle=±2px 悬浮呼吸（4 帧、200ms/帧）+ 地面涟漪椭圆 3 帧扩散循环；脚步声消失的视觉代偿=落地尘帧删除、移动改平移（删除弹跳量）。
- **像素剥落中的小满**：走路循环照常+剥落粒子层独立（碎屑色取自本体色板，2×2px，下落 3 帧、地面停留 ~1s、淡出 2 帧；越走密度越高=粒子生成率参数，帧本身复用）。
- **旧版本立绘**：悬空微浮 ±1px；「极轻微向左偏一次头」=1 帧、持续 100ms、只出现一次（一拍即过）。
- **冲刺态**：俯低（躯干角 +5°）+ 残影（3 个衰减副本：本体色→暗 1 档→暗 2 档，间隔 2 帧位置）+ 发梢向后 2px。残影=smear 的省法，比加中间帧更有速度感。
- **糖·三秒无敌态**：本体 +1 档亮度脉冲（4 帧呼吸）；受击物碎裂=白色碎片 4 帧扇形散开（爆炸教程的粒子法，色取受击物自身）。
- **梦境·变小形态**：同比例缩绘制（不缩放成图）：头身比不变、帧盒 24×24 重画——直接缩放会破簇，重画才保像素纯度。

### 3.5 手感与演出帧

- 跳跃/滑铲/急坠按「分段处理」思路交引擎：起跳/滞空/下落/落地独立切片，配合 coyote time 与输入缓冲（程序侧），美术只需保证**段与段的衔接帧**（每段首帧=上段末帧姿态延续）。
- 出门八拍、点灯、墙三态、回头倒放：先出「分镜关键帧板」（每拍 1 帧、共 ~10 帧）审情绪节奏，再补中间帧——与总案「演出分镜放最后」的顺序一致。

## 四、验收自查清单（合并 A-H2 五条 + 新增六条）

1. 尺寸对：角色高 40px，动画都在 48×48 帧盒内（梦·变小形态除外，24×24 帧盒）。
2. 图层拆好：表情/姿态/服饰三组命名清楚。
3. 颜色合规：只用当前色区色板；单场景 ≤32 色；跨层复用优先。

5. 向左箭头只出现在《小一号的课桌》。

8. 【新】视差层每帧位移整除 480；层内循环帧数整除层总帧数。
