# 美术学习资料·索引

本目录是「游戏开发美术：角色 / 背景 / 动作设计」的学习资料库，全部来自可自由获取的公开渠道（作者公开免费发布的教程、古腾堡计划公共领域书籍、公开镜像仓库），于 2026-09-26 建立。

## 先读什么

1. **`00-学习笔记-角色背景动作三方向.md`** —— 全部资料的研读总结，按角色/背景/动作三方向整理，每条注明出处。
2. **`《浮生》角色与背景动作设计指南.md`** —— 把学习成果落到《浮生》项目的具体设计规范（对 A-H1/A-H2 手册的补强建议稿）。
3. 然后按需查下面的原始资料。

## 目录结构

### `01-像素画教程-saint11/`
Pedro Medeiros（saint11）像素画教程图集，95 个文件。用看图软件逐张浏览，文件名即主题。
与本作最相关的：`RunCycleSimple.gif`（跑循环）、`Walk.gif`（行走）、`Jump.gif`（跳跃分段）、`Squash.gif`（挤压拉伸）、`MotionBlur.gif`（动态模糊/残影）、`Subpixel.gif`（次像素）、`Silhouette.gif`（剪影）、`characterIdle.gif`（待机）、`Shading.gif`/`Outlines.gif`（着色/描边）、`CLouds.gif`、`Vegetation1-3`、`Water.gif`、`Wind.gif`、`Parallax.gif`（背景）、`Easings.gif`（缓动）、`Breaking.gif`（碎裂，糖纸无敌态参考）。
来源：patreon.com/saint11（作者公开免费阅读的教程系列，GitHub 公开镜像备份）。

### `02-书籍/`
古腾堡计划（Project Gutenberg）公共领域书籍，含完整插图版 HTML 与提取的纯文本 `book.txt`：
- `gutenberg-14264/` Harold Speed《The Practice and Science of Drawing》(1913)——线条/块面/节奏/平衡/比例。重点读第 X～XVI 章。
- `gutenberg-30325/` John Ruskin《The Elements of Drawing》(1857)——观察法、主线条、大块明暗。
- `gutenberg-25290/` Walter Crane《Line and Form》(1900)——线的语言、母题、空间填充、辐射原理。
来源：gutenberg.org（公共领域，可自由使用）。

### `03-教程-slynyrd/`
Slynyrd（Raymond Schlitter）博客精选 14 篇，每篇三个部分：离线 `*.html`、正文 `*.md`、`*-images/` 配图。
文件名即主题：01 色板、06 光影、07 风格养成、08 动画入门、11 风景像素、13 岩石、15 植物、17 人体解剖、23 视差滚动、25 运动循环、29 动漫脸与发型、33 风效果、50 人类行走循环、62 风景背景。
来源：slynyrd.com（作者免费公开的教程博客）。
